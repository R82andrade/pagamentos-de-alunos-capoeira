Controle de Gastos com Gráficos
Sistema web para gerenciamento de gastos pessoais com visualização de dados através de gráficos interativos.

📝 Sobre o Projeto
Este é um aplicativo web de controle financeiro que permite aos usuários:

Registrar gastos com descrição e valor

Visualizar uma lista completa de todos os gastos

Atualizar ou excluir gastos existentes

Ver um gráfico visual representando a distribuição dos gastos

Acompanhar o total acumulado de despesas

🎨 Design & Interface
Layout
Design limpo e minimalista: Foco na usabilidade

Organização por abas: Gastos, Gráficos e Relatórios

Responsivo: Adaptável a diferentes tamanhos de tela

Elementos Principais
Header: Título principal do sistema

Navegação: Menu com links âncoras para seções

Botões de Ação: Listar Gastos, Adicionar/Atualizar

Área de Saída (Output): Exibição de dados e mensagens

Canvas: Renderização do gráfico com Chart.js

Totalizador: Soma de todos os gastos

Formulário Modal: Para adicionar/editar gastos

🛠️ Tecnologias Utilizadas
Tecnologia	Descrição
HTML5	Estrutura semântica da página
CSS3	Estilização e layout (arquivo styles.css)
JavaScript	Lógica de negócio (arquivo script.js)
Chart.js	Biblioteca para geração de gráficos
Font Awesome	Ícones vetoriais (via CDN)
